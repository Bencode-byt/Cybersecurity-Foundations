
# Cybersecurity Foundations

Hands-on labs and study notes documenting my cybersecurity learning journey, starting with Linux, networking, Python, and cryptography fundamentals.

## About this repo

This is the first of several repos tracking my progression through a structured cybersecurity roadmap:

1. **Foundations** (this repo) — Linux, networking, Python, cryptography basics
2. **Offensive Security Labs** — pentesting, exploitation, web app hacking
3. **Blue Team / SOC Labs** — forensics, incident response, monitoring
4. **Specialization** — cloud, IoT/SCADA, OSINT

## Structure

- `/linux-notes` — command-line references and exercises
- `/networking` — subnetting practice, packet capture analysis
- `/python-scripts` — tools built while learning Python for security
- `/crypto` — hashing and encryption exercises
